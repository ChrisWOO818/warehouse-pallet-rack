# 📦 창고 파렛트 렉 관리 앱 (Warehouse Pallet Rack Manager)

창고 내 파렛트 렉(A동~G동, 각 열/층/좌우)의 적재 품목 정보를 실시간으로 기록, 자동 저장 및 검색할 수 있는 모바일 최적화 웹앱입니다.

---

## ✨ 2. 핵심 기능

1. **상단 기록 요령 고정 안내 배너**:
   - `품목 기록 요령 - 사용 모델 명, 부품명, 입고일 순으로 기재 ex) APST-2031, 모터, 261027`
2. **동별 드롭다운 및 퀵 탭 전환**:
   - `전체 (A동~G동)`, `A동`, `B동`, `C동`, `D동`, `E동`, `F동`, `G동` 선택 지원
   - 전체 선택 시 A동부터 G동까지 전 구역 순차 표시
   - 개별 동 선택 시 해당 동의 1열부터 끝 열까지 층별(상층~1층) 좌/우 슬롯 입력창 집중 표시
3. **실시간 자동 저장 (`localStorage`)**:
   - 글자를 입력하거나 수정하는 즉시 기기 내에 영구 저장 (새로고침하거나 브라우저를 닫아도 안전)
   - 상단에 `✓ 즉시 자동 저장됨` 녹색 인디케이터 표시
4. **강력한 실시간 품목 검색**:
   - 모델명, 부품명, 입고일, 랙 번호(예: `모터`, `APST-2031`, `261027`, `A-01`) 입력 시 즉시 매칭 결과 목록 표출
   - 검색 결과 클릭 시 **해당 랙 위치로 부드럽게 자동 스크롤 및 노란색 테두리 하이라이트 애니메이션**
5. **작업자 편의 기능**:
   - `+오늘 날짜` 원터치 버튼: 오늘 날짜(YYMMDD)를 자동으로 텍스트 뒤에 추가
   - `비우기` 버튼: 출고 시 한 번에 슬롯 초기화
   - `엑셀/CSV 다운로드`: 전체 파렛트 렉 적재 현황을 스프레드시트 엑셀 파일로 추출
   - `JSON 백업/복원`: 기기를 변경하거나 팀원과 데이터를 주고받을 수 있는 백업/복원 지원

## 📱 3. 안드로이드폰에서 사용하는 방법

### 방법 A. 안드로이드폰 '홈 화면에 추가' (PWA - 가장 추천 ⭐⭐⭐)
별도 빌드나 복잡한 설치 없이 스마트폰 앱처럼 설치하는 가장 쉬운 방법입니다:
1. `index.html` 파일을 카카오톡 나에게 보내기, 구글 드라이브, 또는 개인 웹 호스팅(GitHub Pages, Vercel, Netlify 등 무료 호스팅)에 업로드합니다.
2. 안드로이드 폰 **Chrome(크롬) 브라우저**에서 해당 주소(또는 파일)를 엽니다.
3. 브라우저 우측 상단 메뉴(점 3개 `⋮`)를 누르고 **[홈 화면에 추가]** 또는 **[앱 설치]**를 클릭합니다.
4. 바탕화면에 실제 앱 아이콘이 생성되며, 실행 시 주소창 없는 **전체화면 네이티브 앱**으로 동작합니다. (오프라인 캐시 지원)

### 방법 B. PWABuilder로 1분 만에 .apk 생성 (간편 APK 제작 ⭐⭐)
1. 웹앱을 Vercel이나 GitHub Pages 등에 올린 후 해당 웹 URL을 준비합니다.
2. PC에서 [PWABuilder.com](https://www.pwabuilder.com)에 접속하여 URL을 입력합니다.
3. [Package for Android] 버튼을 클릭하면 구글 플레이스토어 등록용 및 폰에 직접 설치 가능한 **`.apk` 파일**이 자동 생성되어 다운로드됩니다.
4. 다운로드된 `.apk` 파일을 안드로이드 폰으로 전송하여 터치하면 설치됩니다.
